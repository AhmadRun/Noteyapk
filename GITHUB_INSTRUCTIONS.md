# How to Upload Notey to GitHub Manually 🐙

Since `git` commands might not be set up on your computer, here are the two easiest ways to upload your project yourself.

## Method 1: Using GitHub Desktop (Recommended) ✅
This is the best way to handle folders and updates.

1. **Download & Install**: [GitHub Desktop](https://desktop.github.com/).
2. **Login**: Sign in with your GitHub account.
3. **Add Local Repository**:
   - Go to **File** -> **Add Local Repository**.
   - Choose the `Notey` folder: `C:\Users\ahmad\Documents\project\Notey`.
   - Click **Add Repository**.
   - It will ask to "Create a repository here" -> Click **Create Repository**.
4. **Publish**:
   - Click the **Publish repository** button in the top toolbar.
   - Name it `Notey`.
   - Uncheck "Keep this code private" if you want it public.
   - Click **Publish Repository**.

---

## Method 2: Usage GitHub Website (Drag & Drop) ☁️
Good for a one-time upload, but harder to update later.

1. **Create Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Name it `Notey`.
   - Scroll down and click **Create repository**.
2. **Upload Files**:
   - Look for the link: **"uploading an existing file"**.
   - Drag and drop your **entire** `Notey` folder contents into the browser window.
   - *Note: This might take a while and might skip some hidden files or large build folders.*
3. **Commit**:
   - Wait for files to upload.
   - Type "Initial Commit" in the box at the bottom.
   - Click **Commit changes**.
