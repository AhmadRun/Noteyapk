# Notey 📝

**Notey** is a modern, secure, and beautiful Android notes application built with **Kotlin** and **Jetpack Compose**. It features a stunning **Glassmorphism UI**, biometric security, and full offline capabilities.

## ✨ Features

- **🎨 Glassmorphism Design**: High-quality frosted glass UI components.
- **🔐 Secure**: 
  - Biometric Authentication (Fingerprint/Face Unlock).
  - Encrypted PIN fallback (SHA-256).
- **📂 Organization**:
  - Smart Folders/Categories.
  - Search & Filter by category.
  - Color-coded notes.
- **🌓 Themes**:
  - Dark Mode (Default)
  - Light Mode
  - **Cyberpunk Mode** (Neon Aesthetics)
- **☁️ Backup & Restore**: Export your notes to JSON and keep them safe.
- **⏰ Reminders**: Offline scheduled notifications.
- **📱 Widget**: Quick access home screen widget.
